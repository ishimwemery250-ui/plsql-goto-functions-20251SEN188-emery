# plsql-goto-functions-20251SEN188-emery




In this assignment, I practiced different PL/SQL concepts including GOTO statements, stored functions, exception handling, and using functions inside SQL queries.

I started by creating sample tables and data for employees and departments. I then worked on the GOTO exercises, where I classified numbers, reviewed salary values, looked at an illegal GOTO example, and rewrote one program without using GOTO.

In the functions section, I created functions to calculate annual salary, years of service, tax, and return the name of a department. I also tested these functions using SQL SELECT statements.

## Repository Structure
00_setup contains the table creation and sample data
01_goto contains the GOTO exercises
02_functions contains the stored functions
03_tests contains the test queries
screenshots contains screenshots of the outputs
