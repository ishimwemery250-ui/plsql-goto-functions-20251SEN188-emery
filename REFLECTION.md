# Reflection

I learned how GOTO works and how it moves the program to a specific label. I also learned that there are places where GOTO cannot be used.

The function exercises helped me understand how a function receives a value, does some work, and returns a result. I created functions for annual salary, years of service, tax, and department name.

I also learned how to use functions inside SQL queries and how exception handling can help when a record is not found.

The payroll task helped me see how different functions can work together in one program.
